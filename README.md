# ANOR

Адаптивный демонстрационный шаблон ресторана в Таджикистане. HTML, CSS и JavaScript без сборки и установки зависимостей.

## Просмотр

Откройте `index.html` в современном браузере. Шрифты загружаются из Google Fonts; без интернета используются системные шрифты. Фотографии находятся в папке `assets`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub. Для бесплатного аккаунта используйте публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория: `index.html`, `style.css`, `app.js`, `assets`, `.nojekyll` и `README.md`. Загружать нужно распакованные файлы, а не ZIP-архив. `index.html` должен находиться непосредственно в корне, не во вложенной папке.
3. Сохраните файлы в ветке `main` (либо используйте название своей ветки).
4. Откройте **Settings → Pages → Build and deployment**.
5. В **Source** выберите **Deploy from a branch**, затем вашу ветку и папку **/(root)**. Нажмите **Save**.
6. Дождитесь завершения публикации. Ссылка на сайт появится в разделе **Settings → Pages**. Её можно отправлять клиентам.

Последующие изменения в выбранной ветке будут публиковаться автоматически. Настраивать GitHub Actions вручную не требуется.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Адаптация под ресторан

- `index.html`: название, история, адрес, часы работы и контакты.
- `style.css`: переменная `--accent` задаёт основной цвет.
- `app.js`: массив `dishes` содержит меню, цены и категории.
- `assets/`: замените изображения фотографиями ресторана и его блюд.

Кнопка «Примерить свой стиль» позволяет показать другое название и цвет. Эти изменения действуют до обновления страницы. Для постоянной настройки отредактируйте файлы.

## Ограничения демонстрации

Название, меню, цены и расписание — демонстрационные. Форма бронирования показывает результат на странице, но ничего не отправляет и не сохраняет. Для рабочего сайта необходимо указать реальные данные и подключить согласованный с рестораном способ получения заявок.
